✳ О ПРОЕКТЕ

Как устроена
карта навыков.

NextStep Lab — эксперимент с интерфейсом карьерной навигации и объяснимым сопоставлением компетенций. Это личный исследовательский прототип, а не сервис оценки кандидатов.

01 / INPUT

Текст о навыках

Пользователь описывает проекты, знания и интересы свободным текстом. Словарь ищет упоминания инструментов и методов. Он не понимает контекст так же, как человек, поэтому распознавание может ошибаться.

02 / COMPARISON

Шесть учебных профилей

Каждое направление задано вручную как набор навыков с весами. Процент показывает, какую часть весов удалось обнаружить в тексте. Это не объективная оценка уровня человека и не прогноз трудоустройства.

03 / PRACTICE

Задания на две недели

Алгоритм выбирает до трёх навыков для развития и предлагает небольшие практические задачи. Сохранённые планы и отметки выполнения живут только на текущем устройстве.

04 / OPTIONAL AI

Дополнительный AI-комментарий

Отдельная функция может сформировать персональное пояснение через языковую модель. Она доступна только при настройке серверного API владельцем сайта; основной расчёт от неё не зависит.

ПРЕДЕЛЫ МЕТОДА

Что важно учитывать

Профили ролей придуманы для демонстрации механики. Они не взяты из текущих вакансий и не заменяют консультацию с наставником. Алгоритм может не распознать знакомый навык, если он назван иначе; простое упоминание навыка не доказывает уровень владения им.

ТЕХНИЧЕСКИЕ ЗАМЕТКИ

Локальный журнал взаимодействий

Для изучения пользовательских сценариев записываются только названия действий и их время. Текст профиля не попадает в журнал. Эти записи не отправляются на сервер.
